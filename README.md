# SkillForge AI — Professional B.Tech Project

## Modules
1. Student profile & manual skill entry
2. Resume PDF skill extraction
3. 24-career recommendation engine
4. Skill-gap analysis
5. Career readiness score
6. Personalized learning roadmap
7. Portfolio project suggestions
8. Job-description matcher
9. Admin analytics dashboard
10. SQLite history

## Run
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000

## Suggested future AI upgrade
Connect Gemini/OpenAI to the existing backend for natural-language career mentoring, resume feedback, interview questions, course recommendations and dynamic roadmap explanations.
